# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-09-27

### Added
- Native macOS menu bar app (SwiftUI `MenuBarExtra`, window style), read-only by design.
- Menu bar item with a status dot and one optional stat (points, latency, collections), adapting to light and dark menu bars, with a tooltip.
- Popover with a hero (points, state, version, latency), and Overview, Collections and Servers tabs, plus an attention strip that appears only when something needs action.
- Collection detail screen: status, optimizer state, indexing progress (exact scan for small collections), vectors, storage and sharding, payload indexes, aliases, snapshots, and an explanation when a collection is not green.
- Copy collection JSON, copy `curl` (percent-encoded and single-quoted), and open in the Qdrant dashboard.
- Multiple server profiles with a quick switcher, onboarding wizard, and Add Server screen.
- Test connection verifies the API key against `/collections`, so a rejected key is reported.
- API keys stored in the macOS Keychain.
- Remote `http://` servers are refused unless allowed per server; friendly error and a visible marker when allowed.
- Settings: menu bar stat, refresh intervals (popover and background), Launch at login, and Appearance.
- App icon and logo, generated by `scripts/make-icon.sh`.
- Build scripts (`build-app.sh`, `make-dmg.sh`, `release.sh`, `make-icon.sh`) for a universal `.app` and `.dmg`.
- Swift Testing suites for the client, models, connection policy, settings and menu bar logic.
